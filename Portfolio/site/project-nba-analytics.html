NBA Player Performance Analytics

Using regression and dimensionality reduction to understand variation across player performance.

Anna Kim · Python · NumPy · Regression · PCA

GitHub repository link coming soon
1Context 2Approach 3Findings 4What I learned

Track 1

Context

Player-performance statistics describe related parts of the same game, making it difficult to see which patterns are distinct and which move together.

Track 2

Approach

I compared linear and nonlinear regression approaches, then used NumPy to perform principal component analysis through singular value decomposition.

Track 3

Findings

The regression work showed how different model forms frame relationships among player statistics, while PCA offered another view of the major directions of player-performance variation.

Working in the lower-dimensional component space made it easier to examine shared structure across correlated measures without treating every original statistic as independent.

Track 4

What I learned

I learned to use linear and nonlinear models as complementary perspectives instead of assuming that additional complexity automatically creates a better explanation.

Implementing PCA via SVD in NumPy also connected the underlying linear algebra to an interpretable question: how can many related measurements become a smaller set of meaningful patterns?
