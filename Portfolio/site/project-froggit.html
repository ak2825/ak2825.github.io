Froggit

A Python game shaped by object-oriented structure, responsive events, and dependable state.

Track 1

Context

Froggit is an interactive Python game where movement, hazards, and changing game conditions all need to stay synchronized while the player acts.

Track 2

Approach

I organized the program with object-oriented roles and event-driven logic, giving the game a structure for handling input, collision detection, and state changes.

Track 3

Findings

The completed design separates game objects and their responsibilities while a shared event loop coordinates movement and updates.

Collision detection connects what appears on screen to the current state, so player interactions consistently feed into the next game condition.

Track 4

What I learned

State management becomes easier to reason about when each object has a narrow responsibility and transitions happen in predictable places.

I learned that modular design is not just code organization: it makes event-driven behavior easier to test, trace, and extend without losing the game’s logic.
